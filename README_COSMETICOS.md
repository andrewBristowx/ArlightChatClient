# Integración de cosméticos

Esta versión recibe estados desde ArlightCosmetics 1.0.0 mediante el canal
`arlightcosmetics:sync`.

Los modelos son composiciones voxel de bloques e ítems vanilla, por lo que no
requieren un resource pack nuevo. Todos los jugadores deben utilizar esta
versión o una posterior para ver los accesorios.

## Compilación

En Windows:

```text
gradlew.bat build
```

Resultado esperado:

```text
build/libs/ArlightChatClient-3.1.0.jar
```
