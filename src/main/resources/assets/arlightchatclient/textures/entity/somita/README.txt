Texturas finales de la guía Somita (Minecraft Java 64x64, modelo slim):

- overworld.png: maid aventurera con delantal, moños y broche esmeralda.
- nether.png: vampiresa elegante en borgoña/negro con detalles dorados.
- end.png: guía astral ceremonial en crema, lavanda y amatista.
- celebration.png: variante festiva blanca/rosa/dorada.

Las cuatro texturas usan el formato UV estándar de una skin Minecraft 64x64,
incluyen capa exterior y están listas para SomitaGuideRenderer.
